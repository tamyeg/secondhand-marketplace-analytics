# Second-Hand Marketplace Analytics

### Python | PostgreSQL | pandas | Data Visualization

## Project Overview

Second-hand marketplaces generate valuable data about product pricing, seller activity, customer interest, and marketplace performance.

This project explores a simulated second-hand marketplace dataset to identify patterns, investigate business questions, and demonstrate how data analysis can support better decisions.

The project uses **synthetic data generated for educational purposes**, not actual Vinted marketplace data.

## Business Questions

The analysis aims to answer the following questions:

1. Which product categories have the highest listing volume?
2. How do listing prices differ across categories?
3. Which sellers contribute the most listings?
4. How does marketplace activity change over time?
5. What insights can help marketplace teams understand pricing and seller behaviour?

## Technologies Used

- **Python:** Data processing and analysis
- **pandas:** Data cleaning, transformation, and aggregation
- **PostgreSQL:** SQL queries and marketplace data exploration
- **Matplotlib:** Data visualisation
- **Jupyter Notebook:** Interactive analytical exploration, if applicable

## Analytical Workflow

1. Generate or import the marketplace dataset.
2. Inspect and validate the data.
3. Explore category, seller, and pricing distributions.
4. Use SQL queries to answer business questions.
5. Visualise patterns and interpret the results.
6. Discuss limitations and potential improvements.

## Dataset

The project uses a synthetic dataset containing 2,400 second-hand marketplace listings.

The records are intended to resemble common marketplace characteristics while avoiding the use of private customer information.

Because the dataset is simulated, findings should be interpreted as examples of an analytical workflow rather than conclusions about an actual company.

## Business Value

The analysis demonstrates how marketplace data can be used to:

- Understand category and listing activity.
- Identify differences in pricing across product groups.
- Examine seller participation.
- Support data-informed decisions about marketplace operations.
- Generate questions for further statistical analysis.

## Future Improvements
